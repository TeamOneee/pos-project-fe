# POS SaaS — Frontend

Multi-tenant Point of Sale for Indonesian UMKM. One codebase serves iOS, Android and web.

Product rules live in [claude.md](claude.md) — that file is authoritative. This one covers how the scaffold is put together.

## Commands

```bash
npm start          # Expo dev server (press w / i / a)
npm run web        # web only
npm run ios        # iOS simulator
npm test           # Jest + React Native Testing Library
npm run typecheck  # tsc --noEmit, strict
npm run lint       # ESLint
npm run format     # Prettier
npm run tokens     # regenerate global.css from design-tokens.js
```

## Layout

```
app/              Expo Router routes (file-based, typed)
components/ui/    Dumb, role-agnostic primitives — vendored, edit freely
components/       App-level composition (theme provider, theme toggle)
features/         Screen-specific composition, by domain
lib/              money, date, number, validation, query client, tokens
stores/           Zustand — cart state only
design-tokens.js  The single source of truth for every colour and scale
```

## Design tokens

`design-tokens.js` is the only file allowed to contain a colour literal. Three consumers read it:

1. **`global.css`** — generated by `npm run tokens`; defines CSS variables for light and `.dark:root`
2. **`tailwind.config.js`** — maps those variables to semantic names (`bg-canvas`, `text-fg-muted`, `border-border-strong`)
3. **`lib/tokens.ts`** — the typed runtime API, for the navigation theme and chart colours

Edit `design-tokens.js`, run `npm run tokens`, and every layer follows. `global.css` is generated — do not hand-edit it.

### Type scale

Two ways to reach the scale, both generated from the same token source:

- `<Text variant="h1">` — the usual path
- `type-h1`, `type-body`, `type-mono`, … — whole presets (family + size + line-height + weight) for non-Text elements

Money is always `variant="mono"`, which carries tabular figures so rupiah columns line up.

### Spacing and radius

Spacing has semantic names on top of Tailwind's numeric scale: `p-md` (12), `gap-lg` (16), `min-h-touch` (44, the accessible minimum). Radius is restricted to the design scale: `rounded-sm` (6), `rounded-md` (8), `rounded-lg` (12), `rounded-full`.

Breakpoints are `tablet:` (≥768) and `desktop:` (≥1280). Mobile is the unprefixed base.

## Things worth knowing

**Money never touches a float.** The API sends `"15750000.00"`; `parseMoney` turns it into the integer `15750000` at the boundary and it stays an integer. `formatIDR` is the only way money reaches the screen, and it never emits a decimal separator. See `lib/money.ts`.

**Tabular figures are a style, not a class.** `react-native-css-interop` maps `font-variant-caps` but not `font-variant-numeric`, so `tabular-nums` reaches web only. `lib/typography.ts` applies `fontVariant` directly for native; `Text variant="mono"` and `Input numeric` both use it. This is one of the few sanctioned inline styles.

**Icons take colours from tokens.** Lucide icons want a `color` prop, not a style, so `components/ui/icon.tsx` wires `cssInterop` to map `className` onto it: `<Icon as={Check} className="text-accent" />`.

**Expo Router owns navigation.** As of SDK 56 it no longer uses `@react-navigation/native` — theming types come from `expo-router` itself (see `lib/nav-theme.ts`).

**Theme.** `ThemeProvider` resolves light / dark / system, persists the choice to AsyncStorage, and drives both NativeWind's `dark:` variant and the navigation chrome.
